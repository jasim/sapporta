# Testing

## Init Project E2E

These tests create real Sapporta projects under the OS temp directory and print
their paths in the test log:

```text
[e2e path] temp parent: ...
[e2e path] project dir: ...
```

Keep generated projects for inspection:

```bash
SAPPORTA_E2E_KEEP_TEMP=1 pnpm test:e2e
```

### Local Source CLI

Tests the current checkout by running `packages/core/bin/sapporta.mjs`.

```bash
pnpm test:e2e
```

### Latest Published npm CLI

Installs `sapporta` from npm in a temp directory, runs
`node_modules/.bin/sapporta init`, then runs the same generated-project checks.

```bash
pnpm test:e2e:npm
```

### Local Source CLI + Docker

Builds and runs the Docker image for a project generated from the current
checkout.

```bash
pnpm test:e2e:docker
```

### Latest Published npm CLI + Docker

Builds and runs the Docker image for a project generated by the latest published
`sapporta` package.

```bash
pnpm test:e2e:npm:docker
```

## Notes

- The npm modes require registry access.
- The Docker modes require a running Docker daemon.
- The generated-project checks write a sample schema, build the workspace, boot
  the server, seed/read data via `curl`, and verify frontend shell routes.
